# Documentação da NED

## Fontes obrigatórias

- [NED Brand OS](NED_BRAND_OS.md) — fonte canônica vigente de posicionamento, identidade visual, logo, editorias, NED OS, histórico, governança e roadmap.
- [Diagnóstico de identidade visual e origem do Brand OS](history/2026-08-04-identidade-visual-e-brand-os.md) — documento histórico incorporado com o raciocínio que conectou Instagram, site, GitHub, logo, espiral, materialidade, editorias e prioridades técnicas.

## Ordem de consulta

1. Ler o `NED_BRAND_OS.md` para saber quais decisões estão aprovadas e vigentes.
2. Ler o registro histórico quando for necessário entender a origem, o motivo ou o contexto de uma decisão.
3. Verificar o estado real do repositório antes de afirmar que uma recomendação já foi implementada.
4. Consultar PRs e commits mais recentes para decisões posteriores aos documentos.

## Regra

Decisões relevantes de marca devem ser registradas no `NED_BRAND_OS.md` com data e versão antes de serem tratadas como definitivas por outros chats, agentes ou implementações.

O registro histórico não substitui o Brand OS. Em caso de conflito, prevalece a decisão mais recente marcada como **APROVADO** no documento canônico.
