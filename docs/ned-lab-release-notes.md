# NED LAB 001 — Resultado compartilhável

Esta entrega adiciona:

- card vertical de resultado em 1080 × 1920 px;
- compartilhamento nativo quando suportado;
- download PNG e cópia de link como alternativas;
- prévia visual do card dentro do jogo;
- rastreamento de jornada, tempo e abandono;
- sessão anônima para relacionar os eventos do mesmo jogador;
- metadados sociais atualizados;
- roteiro, links UTM e checklist de lançamento.

A imagem é desenhada localmente pelo navegador. Nenhuma imagem ou resultado é enviado para armazenamento externo pelo gerador do card.
