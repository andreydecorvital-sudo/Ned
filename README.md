# Ned Marketing

Site institucional e sistema de marca da NED Marketing.

## Fontes obrigatórias da marca

Antes de alterar posicionamento, identidade visual, conteúdo, componentes, experiências, Instagram ou direção do site, consulte:

- [`docs/NED_BRAND_OS.md`](docs/NED_BRAND_OS.md) — fonte canônica das decisões permanentes.
- [`docs/NED_BRAND_OS_1.1_UPDATE.md`](docs/NED_BRAND_OS_1.1_UPDATE.md) — estado vigente da implementação da logo, site, Brand Kit e Destaques.
- [`docs/instagram/HIGHLIGHTS_SYSTEM.md`](docs/instagram/HIGHLIGHTS_SYSTEM.md) — organização e regras das fotografias dos Destaques do Instagram.
- [`docs/history/2026-08-04-identidade-visual-e-brand-os.md`](docs/history/2026-08-04-identidade-visual-e-brand-os.md) — diagnóstico incorporado e contexto que conectou Instagram, site, GitHub, logo, espiral, materialidade e editorias.
- [`docs/README.md`](docs/README.md) — índice e ordem correta de consulta.

O Brand OS registra decisões aprovadas, posicionamento, sistema visual, editorias, regras do NED OS, histórico cronológico, governança e roadmap. A atualização 1.1 registra o que já está aplicado tecnicamente. O arquivo histórico preserva o motivo e a bagagem por trás dessas decisões.

Em caso de conflito, prevalece a decisão mais recente marcada como **APROVADO**, confirmada pelos arquivos vigentes e pelo estado atual do repositório.

## Stack

- Next.js 15
- TypeScript
- Space Grotesk + Bebas Neue
- Lucide Icons

## Rodando localmente

```bash
npm install
npm run dev
```

## Princípio de manutenção

Mudanças relevantes de marca ou direção criativa devem:

1. consultar as fontes obrigatórias;
2. explicar o problema que resolvem;
3. preservar um caminho de reversão;
4. atualizar a documentação com data, versão e justificativa quando a decisão se tornar definitiva;
5. não substituir silenciosamente uma decisão aprovada;
6. não preencher fotos ou ativos ausentes com material genérico ou artificial.
